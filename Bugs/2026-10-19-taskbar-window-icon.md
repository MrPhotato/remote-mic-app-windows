# 运行中的任务栏显示通用窗口图标

- 发现日期：2026-10-19。
- 状态：已定位，等待本地修复包的可见效果验证。
- 影响范围：本机 Windows、0.3.11；与遥控器型号无关。
- 功能点：主窗口任务栏与 Alt+Tab 图标。
- 现象：用户截图中的应用任务栏按钮是通用白色窗口，没有显示新遥控器图标。
- 复现条件：启动 0.3.11 安装版，观察任务栏图标。
- 正常预期：运行中的任务栏按钮显示与应用内一致的新遥控器图标。

## 证据与根因

已安装版本独立读回为 0.3.11。本机不存在指向无线麦的固定任务栏链接。读取该安装版窗口的公开 `WM_GETICON`：`ICON_SMALL` 与 `ICON_SMALL2` 有效，`ICON_BIG` 为零；类大小图标也为零。

Tauri/Tao 当前默认图标路径只设置小图标，项目没有补充大图标。此前 0.3.8 的独立 ICO 修复只覆盖桌面和开始菜单链接，不能覆盖运行窗口图标。不是重新生成同一张图片即可解决的问题，也没有证据要求清理全局缓存。

## 修复范围

主窗口 setup 在窗口所属线程调用 Windows 平台层，校验窗口归属后，从本进程 exe 的内嵌资源加载系统默认大小共享图标，只设置 `ICON_BIG` 并读回。失败记录具体阶段但不阻止应用启动；不更改已有小图标、托盘、用户固定项或 Explorer 状态。

共享图标由系统管理，进程模块常驻；不提前销毁，不销毁返回的旧句柄。重复初始化可复用同一资源。日志只记录阶段、结果、耗时及错误类别，不包含句柄、路径或其他用户身份。

- `passed`：6 项真实隐藏 Win32 窗口测试覆盖大图标回读、小图标保留、重复调用、无效及异进程/线程目标拒绝、加载和设置读回失败；Windows 宿主编译检查通过。
