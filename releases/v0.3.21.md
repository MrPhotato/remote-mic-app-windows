# 无线麦 SayAll Windows 版 v0.3.21 Preview

麦克风自动切换现在跟随遥控器连接：连接就绪后使用保存的虚拟麦克风，断开时恢复连接前的默认麦克风。只打开软件而遥控器未连接时，不切换系统麦克风。

- CABLE 目标固定显示，普通麦克风可以直接选用；手动选择后不会被自动切换抢回。原麦克风已不可用时保留 Windows 当前选择，不猜测其他设备。
- RC003 按键增强补齐配置了长按或双击的普通按键保护，避免长按动作前漏出单击。方向键仅配置单击时仍支持按住连发；默认长按确认执行 Ctrl＋Enter「插队/排队」。
- 区分聊天与标签页：上/下一个聊天使用 Ctrl＋Alt＋[ / ]，上/下一个标签页使用 Ctrl＋Shift＋[ / ]。
- 按键页保留页面切换动画，遥控器、连线与选项依次展开；方向键初始化提示可在应用各页显示。
- 安装界面支持首次选择安装位置和桌面快捷方式选项；升级沿用原安装位置并保留设置。修复运行窗口任务栏图标。

本机 RC003 长按确认、闲置后上键长按及单击/连发已有验收记录。连接触发麦克风切换经过自动化回归，整合版本的实体断连/重连和 RC001 验收另行记录，不宣称所有设备与第三方输入法已通过。

此版本为 Preview。应用内更新须通过固定公钥验签；发布附件提供 SHA256。尚无 Windows Authenticode 签名，系统可能提示未知发布者。不会自动开关系统蓝牙，也不会自动下载安装更新。
