# 无线麦 SayAll Windows 版 v0.3.4 Preview

修复进入「按键」页时，遥控器图示、连线和已保存动作分批出现的问题。

- 调整窗口大小后再进入页面，遥控器与连线直接显示在正确位置。
- 页面显示前先准备已保存的按键配置，避免先显示「未设置」或占位，再跳成实际动作。
- 配置读取期间保留当前页面；快速切换页面时，迟到的读取结果不会把页面切回来。
- 应用列表单独加载，不再拖慢按键配置显示。

升级保留已有设置。语音、按键执行、蓝牙连接和音频路由保持原样。

已完成 233 项前端测试、生产构建、本地完整安装包升级与配置保留核对；在不同窗口宽度及模拟慢速读取下，逐帧检查未发现占位或布局跳变。RC001／RC003 实体遥控器、不同 Windows 缩放比例的完整回归尚未在本次逐项重测。

此版本以 Preview 发布。安装包提供独立 minisign 签名与 SHA256 校验，尚无 Windows Authenticode 签名，系统可能显示未知发布者提示。应用内自动更新仍未启用。
