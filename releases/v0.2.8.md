# 无线麦 SayAll Windows 版 v0.2.8 Preview

本次小版本更新改进遥控器麦克风设置，并修复连接遥控器后普通键盘反引号、波浪号和 Home 被误当成遥控器输入的问题。

## 改进

- “连接与语音”主页面现在显示“语音来源：遥控器麦克风”，提示在 Codex 或语音输入法中选择 CABLE Output 作为麦克风。
- 内部 CABLE Input 转接设备选择移入默认折叠的“高级设置”。只在尚未配置且找到唯一虚拟声卡时自动选择，保留已有设备设置，不改变 Windows 默认扬声器或目标应用的麦克风。
- 设备读取和启用失败直接显示在主页面，避免误提示安装声卡驱动或一直停留在准备状态；支持手动刷新和重新选择。
- 移除 Home／TV 的全局常驻拦截及近期活动武装。普通键盘 Home、反引号和 Shift＋反引号保持原生输入，遥控器映射只接受已确认来源的设备事件。
- 保留用户按键、听写快捷键及默认方案；语音仍为按下开始、松开结束。

## 使用与已知限制

下载 `SayAll-Windows-0.2.8-x64-setup.exe` 安装。安装程序会先请求旧版正常退出，避免强杀造成蓝牙会话残留。

语音仍需 [VB-CABLE](https://vb-audio.com/Cable/)；本程序把遥控器声音送入 CABLE Input，目标应用从 CABLE Output 收音。页面中的麦克风提示不会替你修改 Codex 的设置。若旧虚拟声卡记录已失效，在“高级设置”重新选择当前 CABLE Input 即可。

**遥控器自身的 TV／主页可能同时带出原生反引号／Home，按住时也可能产生原生重复。** 本次优先恢复普通键盘正常输入，尚未实现按设备完全抑制这两个原生按键。其它普通按键既有的闲置首按透传限制仍存在。RC003 返回、音量三键增强仍由用户显式开启，独立 Helper 需要管理员权限。

## 验证范围

功能改动已通过本机 169 项前端测试、5 项键盘隔离定向测试、Windows 构建安装、配置保留、原生界面与完整 Helper 校验。已实际确认麦克风高级设置的展开／折叠、旧端点失效提示和手动恢复后的声音传送就绪。版本发布另外要求精确提交的 Windows CI 通过，发布资产提供源码身份、SHA-256 和独立 minisign 校验。

上述结果不代替完整实体按键和语音识别验收：普通键盘与遥控器同时使用、历史连续反引号现象、严格闲置首用、断连／睡眠恢复、RC001 及目标应用听写仍保留待复验边界。详情见 [本次验证记录](https://github.com/MrPhotato/remote-mic-app-windows/blob/main/Testing/WindowsAudioAndKeyboardIsolation.md)。

自动更新保持关闭。此版本为 Preview，尚未启用 Windows Authenticode；minisign 签名不等于 Windows 开发者证书，不能保证消除 SmartScreen 提示。
