# 无线麦 SayAll Windows 版 v0.3.5 Preview

换上全新的应用图标：银灰色遥控器、黑色按键，搭配靛紫底色与薄荷绿无线声波。

- 参考 RC003 实物外观重绘，适当加宽机身、缩短底部留白，让小尺寸图标也易于辨认。
- 统一应用内标识、Windows 应用与默认托盘图标、安装器及卸载器图标资源。
- 提供 1024px 母版与多种小尺寸图标，兼顾深浅背景。

本次仅更新图标与版本信息，语音、快捷操作、蓝牙连接和音频路由沿用 v0.3.4。

图标设计已由用户确认。图标资源尺寸、透明通道、ICO 解码、实际小尺寸预览及构建资源一致性检查通过；图标 PR 的 Windows CI 通过，本地前端 233 项、Rust 343 项测试通过，6 项原有测试跳过。安装后的任务栏缓存、托盘及安装器实际外观尚未逐项验收；本次未重测 RC001／RC003 真机与第三方语音全链路。

此版本以 Preview 发布。安装包提供独立 minisign 签名与 SHA256 校验，尚无 Windows Authenticode 签名，系统可能显示未知发布者提示。应用内自动更新仍未启用。
