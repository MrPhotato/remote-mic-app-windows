# 无线麦 SayAll Windows 版 v0.3.0 Preview

这次更新调整界面外观，提供统一的浅色、深色与跟随 Windows 模式。

- 半透明面板、柔和背景光和统一的按钮、输入框、浮层样式。
- 保留遥控器示意图及单击、双击、长按的直接配置入口，五个功能页签的列表高度保持一致。
- 调整主页、连接与语音、权限和关于页面的布局与说明。
- 提高浅色主按钮文字的可读性，保留键盘操作时的输入框焦点提示。

语音按下开始／松开结束、按键映射、蓝牙连接、音频路由和设置保存逻辑保持原样。升级沿用已有配置，RC003 增强仍需手动开启。

此版本以 Preview 发布。已完成界面代码审查、前端测试和浏览器界面检查；本机安装升级、Windows 原生窗口不同缩放比例及 RC001／RC003 实体遥控器回归尚未验收。

安装包提供独立签名和 SHA256 校验，尚无 Windows Authenticode 签名，系统可能显示未知发布者提示。应用内自动更新仍未启用。
