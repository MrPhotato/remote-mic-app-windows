# 无线麦 SayAll Windows 版 v0.3.1 Preview

这次更新为界面加入基础动效，切换页面和操作控件时更顺滑。

- 侧栏、外观主题选择和功能分类页签的选中高亮会滑到新位置。
- 切换页面时，新页面轻微上浮，卡片淡入，过渡中玻璃面板保持磨砂效果。
- 开关滑块（包括 RC003 按键增强开关）平滑滑动，按钮和选项按下时有轻微的按压反馈。
- 高级设置和麦克风列表平滑展开、收起；按键编辑面板淡入出现。
- 「鼠标控制」「打开应用」等折叠项的箭头随展开旋转；应用选择窗口和 RC003 方向键提示弹窗淡入出现。

动效只在操作时出现，界面静止时不持续绘制。在 Windows「设置 › 辅助功能 › 视觉效果」中关闭「动画效果」后，只保留简短淡入。

语音按下开始／松开结束、按键映射、蓝牙连接、音频路由和设置保存逻辑保持原样。升级沿用已有配置，RC003 增强仍需手动开启。

此版本以 Preview 发布。已完成前端测试、类型检查、前端生产构建，并在与 WebView2 同内核的 Edge 中逐帧检查了动效；Windows 原生窗口下的动效流畅度、不同缩放比例、本机安装升级及 RC001／RC003 实体遥控器回归尚未验收。

安装包提供独立签名和 SHA256 校验，尚无 Windows Authenticode 签名，系统可能显示未知发布者提示。应用内自动更新仍未启用。
