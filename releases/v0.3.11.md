# 无线麦 SayAll Windows 版 v0.3.11 Preview

现在可以在应用内一键更新，麦克风选择也更直接了。

- 「关于」自动检查本仓库新版本，包含预览版。点击「更新并重启」即可下载、校验、安装并重新打开，显示下载进度和本次更新内容。
- 升级前正常关闭语音和遥控器连接、恢复原默认麦克风；新版启动后切回保存的目标。收尾失败会停止安装，不强杀进程。
- 麦克风平铺显示，CABLE 和其他麦克风均可选择。启动时切换，真正退出时恢复；运行中手动修改的 Windows 默认值不会在退出时被覆盖。
- 修复 CABLE 多通道接口被占用时无法恢复的问题：只尝试同一虚拟麦克风已验证的备用入口。
- 窗口按钮融入液态玻璃标题栏，支持拖动、双击最大化及系统窗口操作。
- 检查更新时保留卡片高度；改进桌面及开始菜单默认快捷方式图标刷新，保留用户自定义图标。

麦克风选择、听写和退出恢复已由本机 RC003 用户确认。新增更新路径已通过自动化、真实发布清单、固定公钥验签及安装器退出超时测试；首次完整自动升级与重启另行记录。RC001、睡眠后恢复及所有第三方语音软件尚未逐项复测。评论反馈的连续语音中断问题仍在调查，本版不宣称已解决。

此版本为 Preview。更新包必须通过内置公钥验签后才能安装；发布附件另提供 SHA256。尚无 Windows Authenticode 签名，系统可能提示未知发布者。启动检查不会自动下载或安装。
