# 无线麦 SayAll Windows 版 v0.2.7 Preview

这是面向 Windows 与 Codex 遥控操作的独立开源派生版本，基于 [SayAll Windows](https://github.com/GetSayAll/remote-mic-app-windows)，产品灵感与 Mac 原版来自 [HD838A/remote-mic-app](https://github.com/HD838A/remote-mic-app)。不是 SayAll 或 OpenAI 官方发行。

## 改进

- RC003 实验性三键增强：通过图例上方显式开关补齐返回和音量＋／－，使用 Frida 的独立 Helper 申请管理员权限。基础语音与原本可用按键不依赖增强；不修改驱动或关闭 Secure Boot。
- 一键 Codex 日常方案：音量＋／－为 Ctrl+PageUp／PageDown；TV 单击 Ctrl+Alt+B、双击 Ctrl+B、长按 Ctrl+Z；返回普通退格，快按逐次删除，按住连续删除，双击默认关闭。
- 单击／双击／长按均可按支持的动作自由修改或禁用；应用方案前保留首次与最近配置备份。语音维持按下开始、松开结束。
- 修复语音会话开始导致三键 Helper 不必要重绑，以及并发保存、导入或重置时磁盘与运行配置可能不一致的问题。
- 连接失效先发布不可用状态，再执行可能阻塞的清理，避免旧连接继续被当作可用。
- 补齐 Enter 的物理扫描码，修复 Ctrl+Enter 等组合键在 WebView 中丢失按键标识的兼容问题。保留用户已配置的确认键长按动作。
- 完整打包 Helper，增加文件与内嵌清单校验，签名和下载链接使用本 fork 身份；生产界面不包含临时测试输入框。

## 使用与边界

需要 Windows x64、WebView2、兼容且已配对的遥控器。语音需自行安装 [VB-CABLE](https://vb-audio.com/Cable/)，应用输出设为 CABLE Input，目标应用麦克风选 CABLE Output，并配置语音快捷键。按键作用于前台窗口，切换范围也可能经过 Codex 标签页；Ctrl+Z 的撤销范围由目标应用决定。

下载 `SayAll-Windows-0.2.7-x64-setup.exe` 安装；开始菜单名称仍为 `Remote Coding`。键盘来源的部分普通键在闲置后首次按下时仍可能先透传一次原生动作，配置长按不保证拦住这次原生 Enter；这一限制与已修复的 Ctrl+Enter 扫描码问题不同，见应用按键页提示。

本机 RC003 的三键上报、普通返回快速／长按删除、增强开关与基础语音到虚拟声卡已有旧版实测记录。此次连接代次及配置事务修复已有自动化回归，本地安装升级、启动、配置保留和并发保存已验证。**新包的完整实体三键／语音、严格闲置首用、断连／睡眠、最终预设的完整 Codex 动作和 RC001 仍有待复验项目**。这是按维护者明确要求提供跨电脑试用的 Preview，不代表 RC001／RC003 全矩阵验收通过；遇到问题请附复现步骤反馈。

应用自动更新关闭。公开 Preview 构建须提供 minisign `.sig`、公钥、源码元数据和 SHA-256；当前未启用 Windows Authenticode，minisign 不等同于消除 SmartScreen 提示。不要把本地未签名候选当成正式可信安装包。
