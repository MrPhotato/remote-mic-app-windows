# 无线麦 SayAll Windows 版 v0.2.16 Preview

这次更新汇集了 0.2.8 之后的按键映射、麦克风设备识别和 RC003 增强改进。升级会保留已有按键、语音和音频设置。

## 按键更容易配置

- 保留遥控器图和单击、双击、长按的直接点击入口。已知组合键显示功能名称；Esc、Backspace、Enter 等单键保留按键名。
- 快捷键录制放在顶部，功能分为“常用、聊天、编辑、视图、系统”五个页签，支持跨分类搜索。移除成排的 Ctrl／Alt 加数字选项，仍可自行录制。
- “常用”会根据成功分配的次数和最近分配时间调整，也可手动置顶。没有匹配内置功能的自定义快捷键同样可以保存、搜索和再次使用。
- “鼠标控制”和“打开应用”保留独立入口，切换页签或搜索时仍可找到；当前鼠标动作的参数持续显示。各页签列表高度一致。
- 全新安装直接启用默认配置。聊天切换改用 Ctrl+Shift+[ / ]，新增“插队/排队”（Ctrl+Enter，默认分配到电源键长按）。已有配置不会被自动覆盖，可在按键页主动应用默认方案。

## 麦克风与连接

- 麦克风列表现在读取实际录音设备，正确区分 CABLE Output 和内部传送声音的 CABLE Input；高级设置列出录音设备，当前内部传声线路可展开查看。
- 对保存的虚拟声卡端点失效、设备列表暂时不可用和可确认的替代线路补充恢复与诊断，避免把“已配置”误显示为“当前可用”。
- 移除自动开关整机蓝牙及重启蓝牙适配器的恢复逻辑。连接重试仅限选中的遥控器。
- 改善型号识别暂时失败后的重试，以及诊断日志打开或写入失败后的恢复。

## RC003 按键增强

- 启用增强后，等待初始化时弹出“按一下方向键”提示；按遥控器任意方向键并松开后自动关闭。可暂时收起，也可手动重开。
- 修复所选 RC003 的 TV 映射附带原生字符问题，保持普通键盘反引号和波浪号的原有输入路径。
- 修正增强组件通信在空闲时可能忙等的问题。

## 安装与使用

下载 `SayAll-Windows-0.2.16-x64-setup.exe` 安装。安装程序会请求旧版正常退出，保留用户设置。

语音仍需 [VB-CABLE](https://vb-audio.com/Cable/)：无线麦将遥控器声音送入 CABLE Input，Codex 或其它听写应用应选择 CABLE Output 作为麦克风。本程序不修改 Windows 默认扬声器，也不会替你修改第三方应用的麦克风或快捷键设置。语音仍为按下开始、松开结束。

RC003 增强为可选功能，需要用户显式开启并确认管理员授权；基础语音不依赖该权限。每次重新建立增强连接后，仍需按提示真实按下方向键并松开，弹窗会在就绪后自动关闭。

## 验证范围与已知限制

- 本地前端 219 项回归、Windows Rust 回归、安装升级、配置保留及完整增强组件打包已验证。用户已确认当前 RC003 听写恢复出字、TV 不再附带字符、按键页交互正常，以及初始化弹窗按键后自动关闭。
- 发布另外要求精确提交的 Windows CI 通过，并校验安装生命周期、生产包、来源元数据、SHA-256 和独立 minisign 签名。历史本地验收与公开发布包的来源及哈希分别记录，不将两个安装器视为相同字节。
- 本次 RC001、严格闲置后首用、断连／睡眠恢复、新默认方案全部实体按键及原生录制的完整回归仍为待验。当前听写成功不代表这些边界全部通过。
- 曾出现的短暂听写失败与黑色提示条滞留已在现场自行恢复，根因尚未确认。其它普通按键既有的闲置首按透传限制也未宣称解决。
