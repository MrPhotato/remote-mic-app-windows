# ADR 0004：遥控器连接期间的默认麦克风切换

- 日期：2026-10-19。
- 状态：默认录音设备切换与恢复已获有限授权；2026-10-19 用户进一步要求改为连接触发。新生命周期自动化及真实接口释放／重选往返通过，安装版实体连接验收待执行；历史 0.3.10 验收独立保留。

## 产品行为

2026-10-20 用户纠正：遥控器目标固定为 VB-CABLE 一类的虚拟 Capture，普通麦克风始终显示在其余列表。虚拟目标未连接时仅保存偏好，保持当前系统默认录音设备不变；所选遥控器连接就绪后才切换，断开后恢复，退出程序时也执行收尾。目标应用须选择“系统默认麦克风”才能跟随；不能读取或修改其私有设备设置。

点击普通麦克风是明确的“立即使用”操作，不替换遥控器目标。逐角色写入并读回确认后结束本程序的恢复所有权，保留用户手动选择；同一进程后续连接变化不抢回，用户显式重新应用 CABLE 才恢复自动接管。失败保留原有回滚／恢复机制。旧版保存的物理目标不再作为遥控器目标应用；仅有唯一可验证的虚拟线路时迁移，否则等待明确选择，不猜测设备。

切换所有权绑定真实 `connection_generation`：同一连接代次的 `Ready`、`Streaming`、`Draining` 期间持续持有，不随单次说话的音频会话编号反复切换。进入连接中、重连中、断开、休眠或失败阶段时释放并尝试恢复；新的连接代次就绪后，先处理未完成恢复，再从当时实际默认值建立新基线。不得把同代次的连续语音误判为重新连接。

连接就绪时，虚拟麦克风仍须先建立经验证的遥控器传声线路；手选物理麦克风只改变系统录音选择，不将遥控器音频写入物理输入。离线保存虚拟目标不建立线路或写系统默认值。Capture 偏好与现有内部 Render 线路分别保存。

窗口 X 继续隐藏至托盘，不把隐藏当作断开。托盘退出、正常升级退出使用统一收尾作为恢复兜底；不强杀已连接进程。

## 授权与接口边界

用户明确选择“允许，仅限麦克风切换和恢复”。这为本功能限定开放 Windows 未公开 `IPolicyConfig::SetDefaultEndpoint`，不代表微软提供兼容性保证。枚举、设备身份、当前默认值及通知继续使用公开 Core Audio 接口；实现置于 Windows 平台层，普通权限运行。

不修改 Render 默认设备、驱动、蓝牙 Radio 或第三方程序私有配置。源码参考和固定版本见 [ATTRIBUTION](../../ATTRIBUTION.md)。

## 恢复规则

Console、Multimedia、Communications 三个 Capture 角色分别记录原值与本程序实际写入值。切换前验证目标是有效录音端，并保存最小恢复记录；每次写入后读回，不能以 API 返回成功代替生效。

本机实际设置 Console 时会联动 Multimedia，写前须保存可能影响的角色，写后登记实际联动结果。外部改变这对角色中的任一项时成对放弃恢复，避免通过另一项间接覆盖用户选择。全部恢复完成后再次逐角色读回；Windows 无法同时保留原本不同值时，保留恢复记录并报告未完成。

同一连接代次内连续切换多个目标时，保持最初基线。检测到外部修改后放弃该角色的恢复资格，重连不自动抢回；用户随后在本程序显式重新选择，才允许重新接管，并以实际应用时的默认值建立新基线。断开和退出仅恢复当前仍等于本程序最后应用值、且未观察到外部改动的角色；原设备不再可用时不猜测另一只设备。恢复必须显式执行并等待结果，不能依赖析构。

部分失败回滚到本次切换前的设备，只处理仍持有恢复资格的角色。持久化失败先停止切换，不能制造没有恢复记录的系统更改。尚未完成的恢复记录在下次成功识别目标后的首次切换前、或正常退出时处理，避免把上次残留目标误认为新的原默认值；不承诺进程崩溃或断电时立即恢复。

默认设备通知没有修改者标识，设置接口也没有原子比较交换。处理自己的迟到通知、外部变化和退出请求竞态；不得宣称消除所有系统级竞争窗口。退出开始后拒绝新的选择请求，超时结果和剩余恢复记录明确记录。

## 验证门槛

- 角色基线、重复选择、读写失败、回滚、过期通知、用户外部修改、持久化失败及并发退出的确定性测试。
- 离线保存不写系统默认值、连接就绪后应用、同代次语音连续持有、断开恢复、新代次重建基线、外部修改后重连不抢回及恢复失败保留记录。
- 在本机以真实 Capture 执行选择、逐角色独立读回、恢复与再次读回；对照三种 Render 默认值保持不变。
- 本地包升级保留既有语音与按键配置；安装版离线启动、连接应用目标、断开与退出恢复、物理麦切换及听写分别记录，不复用旧启动触发版本的验收结论。
- 按本仓库规则先交付本地验证包，不自动授权推送或发布。
