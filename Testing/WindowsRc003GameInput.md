# RC003 GameInput 免驱接口实验

日期：2026-09-20。目标：在现有 Windows 蓝牙连接下，验证公开 GameInput 接口能否
取得返回、音量加、音量减的真实按下/释放；不安装输入驱动、不增加硬件。

## 环境与隔离

- 官方 NuGet `Microsoft.GameInput 3.5.274`，x64，API v3。
- 以只读 MSI 数据库 API 导出内嵌 CAB 并解包，未运行安装序列。
- 探针目录内 `GameInputRedist.dll` 为 `3.5.274.0`，Authenticode 验证为 Microsoft / Valid。
  探针在 `GameInputCreate` 后核对实际加载版本，拒绝静默回退旧版本。
- 系统已安装运行库仍为 `3.3.221.0`。应用目录运行库与旧服务的完整兼容边界
  没有官方明确说明，须保留为结论边界。
- 实验开始时 Secure Boot=enabled，`SayAllHidFilter` 服务不存在，主程序已正常退出。
  本实验未改动启动设置、系统运行库、设备驱动、主程序或用户映射。
- 独立 Raw Input 对照只监听同一产品设备；GameInput 拒绝聚合设备及多目标，
  只读取目标的白名单按键，不采集其它键盘内容或语音，不注入、不吞键。

## 预检证据

- passed：MSVC `/W4 /WX` 编译；加载的运行库确为 `3.5.274.0`，初始化与设备回调注册 S_OK。
- 首次枚举有 13 个设备回调、8 个非聚合键盘回调，目标尚未出现，不能据此判为不支持。
- passed：用户唤醒对照，Raw Input 于 08:59:57.134 至 09:00:00.182 UTC 收到 3 对上键边沿。
  同时 GameInput 于 08:59:57.742 UTC 新增唯一 VID/PID 匹配目标，能力为 `0x10`（Keyboard）。
  因此采样探针改为先有界等待目标出现，避免遥控器闲置状态造成假阴性。
- 旁路 `FindDeviceFromPlatformString` 使用 Raw Input 原样接口路径，返回 `0x80070490`；
  该结果仅描述此路径查找，不能否定后续设备回调已发现目标的事实。

## 正式采样

程序限定唯一目标，尝试原始报告类型的当前读取；每次键盘 reading 也尝试 `GetRawReport`，
即使能力标志未声明 raw 也记录实际返回，避免只凭能力位得结论。

用户序列：上键 2 次 → 返回 3 次 → 音量加 3 次 → 音量减 3 次 → 上键 2 次，
每次松开后间隔约 1 秒。起始第一下可用于唤醒，之后仍须有前后正对照。

正式窗口为 09:04:33.422 至 09:06:33.467 UTC（`sample-02.log`）。用户确认按完上述序列。

| 项目 | 实际观察 |
| --- | --- |
| 目标身份 | 唯一 VID/PID 匹配，非聚合 HID 键盘，无歧义或断连 |
| 能力 | `supported_input=0x10`，`input_report_count=0` |
| 原始类型当前读取 | `0x838A0003`（READING_NOT_FOUND），未返回 reading |
| 前置上键 | 第一下 09:04:32.783 用于唤醒，在 GameInput 注册前；第二下 09:04:33.520/.720 的 DOWN/UP 被 GameInput 收到 |
| 返回 3 次、音量加 3 次、音量减 3 次 | GameInput 均未交付对应事件，也没有未知键盘状态 |
| 后置上键 2 次 | 09:04:41.482/.645 与 09:04:42.132/.295 两对 DOWN/UP 均被 GameInput 收到 |
| 聚合计数 | 6 个 keyboard readings / 6 个语义边沿；6 次 GetRawReport 尝试、0 个原始报告；未知键盘状态 0，回调错误 0 |
| 收尾 | reading/device 回调均成功注销，设备引用已释放，探针自动正常结束 |

Raw Input 对照程序于 09:04:37.718 自动到时，仅覆盖本轮开始的两次上键，
不能声称它覆盖了本轮全部操作或结束对照。正式窗口的前后正对照均来自 GameInput 自身。

- passed：探针实际加载指定版本、唯一设备识别、前后实体上键与释放、后台读取、无错误收尾。
- failed：在上述本机环境中用 GameInput 取得 RC003 返回/音量±输入；没有获得可供应用修复使用的原始报告。
- deferred：系统公共运行库/服务也升级到 3.5 后的独立验证、其它免驱接口、RC001；本实验没有执行这些操作。
- 本结论不证明遥控器没有发送三键信号，也不证明所有纯软件路径均不可能。
  仅凭当前实验不能将 GameInput 接入作为三键修复交付；未修改主程序。

实验后复核：Secure Boot 仍开启，过滤驱动服务仍不存在，系统运行库版本/哈希与预检一致。
