# Windows 安装界面与目录选择

日期：2026-10-20。候选版本：0.3.12。基于 `origin/main` 的
`3724783ec3681c053272aebe659da366142f95bc`；本次只准备本地测试包，不发布。

## 行为边界

- 无参数打开安装包时，显示独立 Vue/Tauri 安装界面，复用应用的玻璃卡片、按钮及窗口控件，跟随系统深浅色。
- 首次安装可输入或浏览选择本地、可写的空目录，支持中文与空格。拒绝盘符根目录、网络路径、重解析点、无效目录和不属于本产品的非空目录。
- 已安装时保留原位置；跨目录迁移需要卸载后重装，不将 `/D` 覆盖误当作迁移。
- 默认创建桌面快捷方式；取消勾选时不创建新桌面快捷方式，也不删除用户已有的快捷方式。开始菜单入口保留。
- 安装期间禁用重复安装和关闭；完成后默认勾选打开无线麦，只有点击完成且保持勾选才启动。
- 安装宿主不依赖 `sayall-windows`，不初始化蓝牙、音频、按键或增强 Helper。
- 显式命令行参数全部转发给原 NSIS，保留退出码与 `/D` 原始 Unicode 参数。应用内升级继续由原安装器使用已有目录、请求正常退出并通过 `/R` 启动一次；不新增麦克风恢复路径。
- 最终外层安装器完成后才签名，内层包与安装后主程序均按编译时 SHA-256 校验。

## 手动验收步骤

1. 手动打开本地安装包，确认标题、目录与桌面快捷方式选项；已有安装目录应只读。
2. 点击开始安装，确认重复点击和关闭受保护；应用如正在运行，应通过正常退出路径收尾。
3. 安装完成后点击完成，确认仅启动一次；核对配置保留、默认麦克风切换和一次遥控器听写。
4. 在干净测试用户或虚拟机上选择中文空目录，分别取消/保留桌面快捷方式；验证开始菜单、启动、卸载及再次安装。
