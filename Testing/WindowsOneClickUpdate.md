# 一键升级验证

范围：本仓库 GitHub Release（含 Preview），仅用户点击「更新并重启」后下载安装。

## 设计边界

- 检查与安装复用同一 Release 选择，点击时重新核实精确版本；清单、安装包必须同仓库、同 Tag。
- 固定应用内公钥验证下载字节，成功后才执行退出收尾；下载或验签失败不关闭语音。
- 更新收尾要求 BLE/按键/音频关闭及默认麦克风恢复实际成功。恢复失败保留 journal 并中止安装。
- 安装到当前已安装目录，安装器完成后重新打开；普通关闭窗口仍隐藏到托盘。
- 新进程重新读取恢复后的 Windows 默认麦克风作为本次基线，再切到保存的目标。退出时不覆盖运行中外部改动。
- 启动检查不会自动下载或安装；失败、旧版本重新启动不显示升级成功。
