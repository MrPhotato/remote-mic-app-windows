## 硬件与应用边界

- RC003 只读枚举得到一个 Raw Input 键盘集合，无单独 consumer 集合；usage 通配范围包含 F1 不能证明返回键实际发送 F1。
- 两次限定于小米设备的被动监听均无事件，也没有取得上键正对照，结果为 inconclusive，不能据此宣称返回键不支持。
- RC003 实体单按、按住连续删除、释放停止、双击和闲置首按，以及 Codex 输入框公开 UIA 兼容性仍为 deferred。
- UIA 选区与 SendInput 不是系统原子事务，最后校验与注入之间仍有竞态；不承诺所有编辑器均可用。

复现原生测试：`cargo run -p sayall-windows --example text_edit_probe -- --run`。测试创建独立临时窗口，失去该窗口焦点就取消；没有 `--run` 参数时不操作桌面。
