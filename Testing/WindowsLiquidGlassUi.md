# 液态玻璃界面审查与本地验证

日期：2026-10-14。原始界面提交：`e4129d2`，基线：`24a1a8f`（v0.2.16）。

## 审查结论

本次改动限于 Vue 展示结构、样式、文案及版本元数据，不修改 Rust、IPC、权限清单、设置结构、依赖或默认映射。9 个 Vue 文件中 7 个 script 块完全相同；其余仅增加读取语音状态的 computed 和图标常量。139 处事件、v-model、disabled、checked、value 绑定逐项比较一致。

发现并修正：

- 浅色主按钮与选中主题原先向白色过渡，降低了小字号白字的对比度。改为从品牌色向深色过渡，最浅端与白字的对比度约 4.93:1。
- 搜索、快捷键名称、鼠标参数和应用搜索的局部 `outline: none` 会覆盖全局键盘焦点规则。去掉局部覆盖，继续使用已有输入方式判定和全局焦点轮廓；Windows 强制高对比去掉阴影时仍有 outline 路径。
- Enter 的效果仍取决于目标应用与焦点，说明恢复为“可能发送内容／批准操作”。

未发现需要改动按键、语音、蓝牙、音频和配置保存逻辑的阻塞问题。
