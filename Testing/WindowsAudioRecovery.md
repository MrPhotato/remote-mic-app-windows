# 麦克风列表与线路恢复验证

适用版本：0.2.12 本地测试包。关联现场：[2026-10-14](../Bugs/2026-10-14-audio-device-direction-and-stale-route.md)。

## 实现边界

- 麦克风列表读取 Windows Capture 端点，分别标记默认录音和默认通信角色；这些角色不代表 Codex 或其他应用的当前选择。
- 遥控器仍是语音来源。选择虚拟麦克风改变无线麦内部的写入线路，不修改 Windows 默认输入、输出设备。
- Capture 与 Render 通过公开拓扑、设备属性确认共同父设备、VB-CABLE 驱动服务和提供者；一根线的两个播放接口不计为两根线。
- 同 ID 恢复接受名称变化；旧 ID 缺失时，仅在旧设备为 NOTPRESENT、旧驱动实例 Code 10 且存在唯一可核验线路时自动跨实例绑定。禁用端点、身份未知和歧义均不自动绕过。
- Windows 设备通知回调只标记和唤醒；音频工作线程在语音会话之外恢复。维护重试最多三次，间隔为 1、5、15 秒，随后等待设备变化或用户重试。这些间隔不改变语音键时序。
- 失效时清除旧 PCM 和会话代次，恢复不重放旧音频。成功线路通过设置锁保存，失败不覆盖保存的选择；保存失败不掩盖实际音频状态。

## 软件回归

覆盖同 ID 改名、唯一虚拟线路、同父设备双接口、多个虚拟设备、驱动身份缺失、禁用端点、重试次数、过期音频、通知队列满、失败后同设备重试、实际录音列表及设置保留。

只读真机探针：`audio_devices::tests::audio_inventory_live`。须显式指定私有配置夹具路径 `SAYALL_AUDIO_PROBE_SETTINGS`；它只输出脱敏计数和判定结果，不开音频流、不操作 BLE，也不打印设备身份。

## 真机验收

1. 保留故障配置，以普通权限启动安装版；记录自动恢复结果与 Capture/Render 对应关系。
2. 高级设置刷新后应显示录音设备及默认角色，普通 Speakers 不得作为麦克风选项出现。
3. 闲置后首次按住语音键，松开后目标应用实际出现文字；继续短按、连续语音，检查语音快捷键成对释放。
4. 对照升级前后的系统默认输入、输出角色、按键配置和 Helper 文件；不修改蓝牙或驱动来完成验收。
5. 端点消失后重新到场、语音中音频设备失效、睡眠恢复、RC001/RC003 分别验收。不得以单元测试代替这些硬件场景。

最终执行结果记录在 `Testing/evidence/audio-route-recovery-20261014.json`；未执行项保持 `deferred`。

## 2026-10-19 占用接口恢复与平铺界面

关联现场：[CABLE 接口被占用](../Bugs/2026-10-19-cable-interface-in-use.md)。

恢复只对 Initialize 的类型化 `AUDCLNT_E_DEVICE_IN_USE` 生效，尝试同一已验证 Capture 下唯一的备用播放接口一次。其他阶段、其他 HRESULT、身份缺失、配对歧义、无备用接口或两个接口均失败，均不扩大选择范围。成功快照使用实际打开的 ID；失败继续保留原设置与既有 1/5/15 秒退避，不重放旧 PCM。

- `passed`：新核心生产路径真机测试 `audio::tests::shared_virtual_peer_recovery_live`（ignored，需显式 `SAYALL_AUDIO_PROBE_SETTINGS`）。原接口实际 Initialize 返回占用，恢复返回同一已验证 Capture 的备用接口，断言实际 ID 与备用 ID 一致。没有 Start、PCM、音量、静音、系统默认或配置写入。
- `passed`：25 项音频定向 Rust 测试，3 项明确 ignored；涵盖错误阶段与类型、唯一配对、身份/歧义拒绝、最多一次备用尝试及两接口失败。
- `passed`：31 项连接页组件测试，含枚举失败后保留并禁用旧列表、自动刷新恢复、同麦克风备用接口成功但保存失败的提示和重试。
- `passed`：工作区 Rust 库回归 355 项、8 项 ignored；前端回归 279 项。包含实际入口持久化、设置失败不覆盖运行状态、PCM 清理与通知退避。最初沙箱套接字和文件权限导致的三个失败在正常 Windows 权限下复跑均通过。
- `passed`：真实 Chromium 16 组组合（1029/1440、浅/深色、已选/失败/列表过期/无设备），无横向溢出及页面错误，诊断默认折叠、可展开；普通麦克风无伪造选择入口，过期选择不会调用后端。
- `deferred`：安装版自动恢复及实际遥控器听写出字、严格闲置首用、连续语音、设备热插拔和睡眠；RC001/RC003 必须分别验收。

主页面直接展示目标虚拟麦克风与其余 Capture。设备名称和角色均来自 Windows 枚举，不表示目标应用已经选中；物理麦克风需在目标应用选择。内部写入端及完整错误只在诊断区展示。
