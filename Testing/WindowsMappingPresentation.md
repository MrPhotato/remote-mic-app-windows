# 0.3.15 按键页呈现与全局方向键提示

## 范围

本次仅调整前端展示和增强状态的前端生命周期。配置内容、触发阈值、原图、
画布外部几何、Helper 及系统实现保持既有行为。

## 检查项目

1. 进入按键页时首帧的遥控器位置正确，保存的动作名称完整；
   连线和卡片短暂依次进入，不出现“未设置”占位替换。
2. 深浅主题、不同窗口尺寸、减少动态效果、首次进入、快速切走再返回、
   动画期间点击及尺寸变化均保持布局完整。
3. 各按键三格上下留白一致，文字没有溢出，点击仍选择原来的触发类型。
4. 开启增强期间切到其它页，等待方向键的提示仍出现；
   用户关闭提示不停止增强，同一代不重复打扰，新一轮初始化可再次提示。
5. 真实 ready、失联、读取失败或型号变化会关闭无效提示；
   恢复等待时不会永久丢失未完成的提示。迟到状态及开启请求不能覆盖新上下文。
6. 安装采用正常退出及静默升级，保留按键、语音、音频设置和完整增强组件。
