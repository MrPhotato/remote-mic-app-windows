# 0.3.19 聊天与标签页快捷键

## 当前可见菜单

2026-10-21 用户提供 Windows 应用“视图”菜单截图，并明确左侧条目叫聊天、右侧区域叫标签页。

| 功能 | 组合键 | 选项位置 |
| --- | --- | --- |
| 上一个／下一个聊天 | Ctrl+Alt+[ / ] | 聊天 |
| 上一个／下一个标签页 | Ctrl+Shift+[ / ] | 视图 |

快捷键目录、已绑定动作的功能名、录制匹配、全库搜索及日常默认使用同一对应关系。
音量＋／－的默认短按继续切换聊天；新安装、恢复默认和手动应用日常方案都读取共享默认。
常用历史保持按功能 ID 统计，录制仍保留实体左右修饰键及原始顺序。
旧 Ctrl+Page Up/Down、Ctrl+Tab 别名本轮未确认，不再识别成聊天功能；已有实际按键不自动改写。

## 行为与配置边界

- Ctrl+Alt 或 Ctrl+Shift 加方括号的音量键单击均为离散动作，按住不重复切换；普通滚动、音量和方向键重复行为保持。
- 沿用现有输入事件成对释放、按键日志及运行时配置保存日志；不改硬件归因、Helper 或注入时序。
- 应用升级不批量迁移用户自定义组合键。本机原配置的两个音量短按确认为此前的聊天绑定，因此仅在正常退出、备份后将它们更新为 Ctrl+Alt+[ / ]；长按滚动及所有其它字段保持。
